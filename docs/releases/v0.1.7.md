# DevBootstrap-0.1.7-x64.exe

작업 진행 상황을 본문 상단 대신 **오른쪽 패널**에 표시하고, 단계마다 그 단계에서 실행한 마지막 작업을 기억합니다.

- 다음 단계로 넘어가면 이전 단계의 작업 표시가 사라지고, 돌아오면 그 결과가 다시 보입니다. 작업이 없는 단계에서는 "이 단계에서 실행한 작업이 없습니다."를 표시합니다.
- 패널은 접었다 펼 수 있습니다. 접으면 상태 점과 경과 시간만 남고, 새 작업이 시작되면 자동으로 펼쳐집니다. 창 너비가 1240px보다 좁으면 펼친 패널이 본문 위에 겹치고, 창을 그보다 좁게 줄이면 자동으로 접힙니다.
- 설치 진행 단계의 "진행 기록 보기"를 없애고 설치 진행 기록을 같은 패널에 표시합니다. 로그 폴더 열기 버튼은 그대로입니다.
- 기본 창 너비를 1160에서 1460으로 넓혀 본문 너비를 유지합니다.
- 드롭다운을 연 직후 뒤늦게 도착한 스크롤 이벤트로 메뉴가 닫히던 문제를 고쳤습니다. 트리거가 실제로 움직였을 때만 닫힙니다.

`DevBootstrap-0.1.7-x64.exe`를 받아 Windows 로컬 폴더에서 실행하세요. 이번 화면 변경은 새 EXE에서 반영됩니다. Git clone은 필요 없습니다.

UI 회귀 테스트 11개(패널 단계별 기록·접기/펼치기 2개 추가), 단위 테스트 14개, 빌드와 Windows EXE 스모크 테스트를 통과했습니다. 앱 소스는 Prettier 형식으로 정리했으며 정리 전후의 빌드 결과가 동일함을 확인했습니다.

서명되지 않은 Pre-release입니다. 0.1.6의 WSL 미설치 PC 재실행 확인과 신규 Windows 전체 설치 검증은 별도로 남아 있습니다.
