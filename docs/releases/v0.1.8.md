# DevBootstrap-0.1.8-x64.exe

집 PC처럼 WSL이 아직 없는 PC에서 흐름을 끊던 두 가지 창을 줄였습니다.

- **SmartScreen·보안 경고는 처음 한 번만**: 앱이 시작되면 다운로드한 EXE의 Mark-of-the-Web(`Zone.Identifier`)을 스스로 지웁니다. 첫 실행에서 "추가 정보 → 실행"을 누른 뒤에는 재부팅 후 다시 열어도 묻지 않습니다. 계속 뜨면 파일 속성의 **차단 해제**를 확인하세요.
- **WSL 준비의 완전 설치 보장**: `wsl --status`에 더해 `wsl --version`이 버전 번호를 돌려줘야(Store판 WSL 패키지 존재) **준비됨**으로 표시하고 다음 단계를 엽니다. 이후 단계에서 wsl.exe가 자기 설치를 마저 하려고 스스로 관리자 권한(UAC)을 요청하는 경우를 막습니다. WSL 준비가 재부팅 없이 끝났는데도 준비되지 않으면 "사용자 작업 필요"로 멈추고 안내합니다. Ubuntu 설치는 준비가 완전하지 않으면 wsl.exe를 부르기 전에 거부합니다.
- PC 상태의 WSL 칸에 확인된 WSL 버전을 표시합니다(예: `준비됨 · 2.7.13.0`).

0.1.7의 오른쪽 진행 상황 패널과 단계별 작업 기록을 포함합니다.

`DevBootstrap-0.1.8-x64.exe`를 받아 Windows 로컬 폴더에서 실행하세요. Git clone은 필요 없습니다.

`tests/app-host.ps1`에 WSL 미설치 스텁 시나리오(준비 필요 판정·Ubuntu 설치 거부)와 Store WSL 완전성 검사를 추가해 7개 검사를 통과했습니다. 단위 테스트 14개, UI 테스트 11개, 빌드, Windows EXE 스모크 테스트, 패키징 EXE의 Mark-of-the-Web 자동 제거를 확인했습니다.

서명되지 않은 Pre-release입니다. 실제 WSL 미설치 PC에서 WSL 준비 → 재부팅 → 재실행 흐름과 UAC 횟수는 사용자 확인이 남아 있습니다.
