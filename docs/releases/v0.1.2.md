# DevBootstrap-0.1.2-x64.exe

설치 화면의 제목·메뉴·이전/다음 버튼을 고정하고 본문만 스크롤하도록 바꿨습니다. 앞 단계의 필수 작업을 완료하기 전에는 다음 화면이 잠깁니다.

## 사용 방법

1. `DevBootstrap-0.1.2-x64.exe`를 받아 Windows 로컬 폴더에서 실행합니다. Git clone은 필요 없습니다.
2. 환경 확인과 Ubuntu 준비를 마치고 설치 구성을 선택합니다.
3. 변경 내용 확인 → 설치 진행 → 로그인·연동 순서로 진행합니다. 실패·중지된 설치는 재시도해야 합니다.
4. KB 인증·Orca 연결 대기는 로그인·연동 화면에서 처리합니다. 선택한 항목 설치와 계정 연결이 완료되면 완료 화면이 열립니다.
5. 커맨드·스킬 업데이트는 별도 유지 관리 메뉴입니다. Ubuntu 환경 확인 후 전체 설치 없이 사용할 수 있습니다.

## Orca 설치

환경 확인 또는 로그인·연동의 **Orca 다운로드 · 설치** 버튼으로 공식 최신 안정판 Windows 설치 파일을 다운로드합니다. GitHub 배포 파일의 크기와 SHA-256을 검증한 뒤 공식 설치 창을 엽니다. 설치를 마치고 **Orca 설치 상태 확인**을 누르세요.

이미 설치된 Orca를 자동 업데이트하거나 덮어설치하지 않습니다. Orca 로그인 후 대상 Ubuntu의 WSL 터미널을 한 번 열고 **Orca 스킬 연결**을 누릅니다. 패치는 기존과 같이 검증된 1.4.202 파일만 지원하며 최신 Orca에 자동 적용하지 않습니다.

## 검증과 한계

- 구성·단계 이동·Orca 다운로드/해시 검증 테스트 10개와 브라우저 UI 테스트 7개를 통과했습니다.
- 최소 창 크기 900×650에서 본문을 스크롤해도 제목·다음 버튼이 고정되는 것을 검증했습니다.
- 공식 Orca 설치 파일의 실제 다운로드와 체크섬을 확인했습니다. 테스트에서는 설치 파일을 실행하지 않았습니다.
- 패키징된 Windows 앱에서 WSL 환경 확인·GitHub 콘텐츠 미리보기·단계 잠금·고정 제목을 확인했습니다.

서명되지 않은 Pre-release입니다. 신규 Windows에서 WSL 준비·재부팅부터 전체 설치하는 검증과 Orca 설치 창을 끝까지 진행하는 실환경 검증은 남아 있습니다.

0.1.1 사용자도 이번 UI와 Orca 설치 기능을 사용하려면 새 EXE를 받아야 합니다. 이후 커맨드·스킬 내용만 바뀌면 기존처럼 앱의 업데이트 메뉴를 사용하세요.
