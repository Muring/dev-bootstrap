# DevBootstrap-0.1.4-x64.exe

시간이 걸리는 작업에 공통 진행 패널을 추가하고, 드롭다운의 펼친 목록까지 앱 스타일로 통일했습니다.

## 작업 진행 상황

- 제목 아래 고정 패널에서 현재 과정, 경과 시간, 단계 이력을 확인합니다.
- 환경 검사는 Windows·WSL·Orca 확인과 Ubuntu 계정·인증·도구 검사를 세분화해 처리한 검사 수를 표시합니다.
- Orca 다운로드는 실제 MB와 퍼센트, 이후 체크섬 검증과 설치 창 실행을 표시합니다.
- 콘텐츠 업데이트는 다운로드한 파일 수, 검증·백업·적용·복구 과정을 표시합니다.
- WSL·Ubuntu 설치, 로그인, 설치 재시도와 재시작에도 현재 작업을 표시합니다. 수치를 제공하지 않는 외부 작업에는 임의의 퍼센트나 예상 시간을 표시하지 않습니다.
- 사용자 입력 대기, 실패, 취소를 구분하고 마지막 작업 이력을 `%LOCALAPPDATA%\dev-bootstrap\last-operation.json`에 저장합니다.

배포판·저장 위치 목록의 배경, 테두리, 선택 표시와 마우스 강조를 통일했습니다. 방향키·Home/End·Enter·Escape·Tab과 목록 밖 클릭을 지원합니다.

## 실행과 검증

`DevBootstrap-0.1.4-x64.exe`를 다운로드해 Windows 로컬 폴더에서 실행하세요. Git clone은 필요 없습니다. 기존 버전 사용자는 새 EXE를 받아야 이번 UI 변경이 반영됩니다.

진행 상태·다운로드 검증·구성 테스트 12개, UI 테스트 9개, 콘텐츠 업데이트 테스트 10개와 설치 순서 회귀 테스트를 통과했습니다. Windows helper와 패키징된 Windows 앱에서 Windows 검사 파일과 Ubuntu 검사 스트림의 실시간 진행 전달을 확인했습니다.

서명되지 않은 Pre-release입니다. 신규 Windows 전체 설치와 Orca 설치 창을 끝까지 진행하는 검증은 남아 있습니다. 외부 설치 프로그램 내부의 상세 퍼센트는 해당 프로그램이 제공하는 범위에서만 확인할 수 있습니다.
