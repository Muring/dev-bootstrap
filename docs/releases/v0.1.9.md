# MuRingDevSetup-0.1.9-x64.exe

이름 변경과 기존 설치 호환성을 확인한 **Pre-release**입니다.

## 변경 내용

- 앱 이름을 **Dev Bootstrap**에서 **MuRing Dev Setup**으로 변경했습니다.
- 새 포터블 실행 파일명은 `MuRingDevSetup-0.1.9-x64.exe`입니다. 화면의 버전 표시도 0.1.9로 갱신했습니다.
- 설치 및 커맨드·스킬 다운로드 원본을 `Muring/muring-dev-setup`으로 전환했습니다.
- 기존 설치 경로·상태 파일·셸 설정·Claude/Codex 링크는 유지합니다. 기존 환경을 삭제할 필요가 없습니다.

## 실행 방법

Windows 로컬 폴더에서 EXE를 실행하고 **환경 확인**을 누릅니다.
기존 사용자는 같은 Windows 계정에서 선택 기록을 불러오며 실제 설치 상태를 다시 확인합니다.
새 PC에서는 WSL 준비 → Ubuntu 설치 → 설치 구성 → 변경 내용 확인 → 설치 → 로그인·연동 순서로 진행합니다.

릴리스 Assets에서 `MuRingDevSetup-0.1.9-x64.exe`를 받으세요. Git clone은 필요 없습니다.
기존 `DevBootstrap-0.1.8-x64.exe` 릴리스도 유지합니다.

## 검증 범위

- 형식 검사, 앱 단위 테스트 14개, TypeScript/Vite 빌드, Windows 포터블 패키징 통과.
- Playwright UI 테스트 11개 통과. Linux에서는 기존 사용자 라이브러리 캐시를 해당 프로세스의 `LD_LIBRARY_PATH`로 지정했습니다.
- 콘텐츠 업데이트 테스트 10개와 설치 순서·재시도, 셸 설정 보존, KB 연결 회귀 검사 통과.
- 실제 Windows에서 `tests/app-host.ps1`, `tests/wsl-location.ps1` 통과.
- 패키지 내부 버전과 화면 버전 0.1.9, 동봉된 설치·콘텐츠 스크립트와 현재 소스의 일치를 확인했습니다.
- EXE를 Windows 로컬 임시 폴더에 복사하고 격리된 `LOCALAPPDATA`로 실행했습니다.
  Windows Node + playwright-core의 CDP 검사로 앱 이름·버전, sandbox preload·IPC, 실제 WSL 환경 검사,
  GitHub 콘텐츠 미리보기, 설치 구성 화면과 고정 제목 스크롤을 확인했습니다.
  최초 CDP 연결은 포터블 압축 해제 중 거부됐으며 앱 준비 후 재시도하여 통과했습니다.
- 실행 검증은 환경 검사와 미리보기 범위입니다. 신규 Windows VM의 WSL 설치·재부팅·Ubuntu 생성·전체 설치,
  기존 사용자 상태의 실제 업그레이드, Orca 패치 실행은 검증하지 않았습니다. 안정판으로 판정하지 않습니다.
