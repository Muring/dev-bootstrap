# DevBootstrap-0.1.6-x64.exe

WSL이 설치되지 않은 PC에서 **환경 확인**이 깨진 문자열과 함께 실패하던 문제를 고쳤습니다. 이제 WSL 미설치 상태를 정상적으로 인식해 **WSL 준비** 단계로 안내합니다.

- wsl.exe는 자기 메시지를 UTF-16LE로 출력하고 Ubuntu 쪽 명령은 UTF-8로 출력합니다. 두 인코딩을 판별해 읽도록 해 한글 안내문이 그대로 표시됩니다.
- Windows PowerShell 5.1에서 wsl.exe의 stderr 출력이 검사 자체를 중단시키던 문제를 없앴습니다. 검사·설치 helper와 단독 실행용 `windows/bootstrap.ps1` 모두 같은 방식으로 wsl.exe 출력을 읽습니다.
- 존재하지 않는 배포판·사용자 등 wsl.exe 오류 문구도 깨지지 않고 표시됩니다.

`DevBootstrap-0.1.6-x64.exe`를 받아 Windows 로컬 폴더에서 실행하세요. 이번 수정은 새 EXE에서 반영됩니다. Git clone은 필요 없습니다.

PowerShell 테스트 2종에 UTF-16LE·UTF-8 디코드 검사를 추가했고, Windows PowerShell 5.1과 실제 WSL에서 오류 문구·배포판 목록·Ubuntu 한글 출력을 확인했습니다. 단위 테스트 14개와 빌드를 통과했습니다.

서명되지 않은 Pre-release입니다. WSL 미설치 PC에서의 재실행 확인과 신규 Windows 전체 설치 검증은 별도로 남아 있습니다.
