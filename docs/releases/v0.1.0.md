Windows 설치 마법사 첫 검증판입니다. **Git clone이나 Node 사전 설치 없이 아래 EXE를 받아 Windows 로컬 폴더에서 실행하세요.**

## 다운로드와 설치

1. Assets의 `DevBootstrap-0.1.0-x64.exe`를 다운로드합니다. `Source code` 파일은 설치 파일이 아닙니다.
2. Windows 11 x64에서 EXE를 실행하고 **환경 확인**을 누릅니다.
3. WSL 준비 → 필요시 재부팅 → Ubuntu 준비 → 설치 구성 → 변경 내용 확인 → 설치 순서로 진행합니다.
4. GitHub·Claude·Codex 로그인과 선택한 KB·Orca 연동을 마칩니다.
5. 새 Ubuntu 터미널에서 선택한 도구의 버전을 확인합니다.

자세한 설치 방법: https://github.com/Muring/dev-bootstrap/blob/v0.1.0/README.md

## 포함된 기능

- MuRing 기본 구성과 공통 개발환경 구성, 항목별 선택과 Recommended 표시
- 기존 .zshrc 보존, 선택적 전체 교체, 변경 파일 백업
- 의존성 처리, 설치 검증, 단계별 재시도, 진행 기록 저장
- 별도 로그인 터미널과 KB·Orca 수동 작업 안내
- 기존 CLI 진입점 유지; 비대화형 실행은 JSON 구성 필요

## 검증 범위와 한계

구성·의존성, 설정 보존, KB, UI 자동 테스트와 실제 Windows 앱 실행·WSL 읽기 전용 검사·WSL 인자 전달을 확인했습니다.
신규 Windows에서 재부팅을 포함한 전체 설치와 실제 Orca 패치 적용은 아직 검증하지 않았습니다.
이 릴리스는 코드 서명과 자동 업데이트가 없는 Pre-release입니다. Orca 패치는 검증된 1.4.202 파일에만 적용할 수 있습니다.

실패하면 앱의 **로그 폴더 열기**에서 실행별 `events.jsonl`과 `events.log`를 확인하세요.
재부팅 또는 중단 후에는 같은 EXE를 다시 실행하고 환경을 확인한 뒤 재시도할 수 있습니다.
다음 버전은 Releases에서 새 EXE를 받으면 됩니다. 기존 Ubuntu를 삭제할 필요는 없습니다.

`SHA256SUMS.txt`는 함께 제공되는 EXE의 SHA-256입니다.
