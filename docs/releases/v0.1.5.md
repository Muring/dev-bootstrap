# DevBootstrap-0.1.5-x64.exe

진행 이력과 설치 로그를 테두리·배경·여백이 있는 박스로 정리하고, 앱 전체 스크롤바를 mublog 관리 화면 스타일로 통일했습니다.

- 현재 작업 메시지, 펼친 진행 이력, 설치 진행 기록을 각각 구분해 표시합니다.
- 본문·로그·드롭다운·메뉴에 투명한 트랙과 얇고 둥근 스크롤 손잡이를 적용했습니다. 마우스를 올리면 강조됩니다.
- 밝은 화면과 어두운 메뉴의 배경색에 맞추고, 스크롤바 공간을 유지해 내용 너비가 튀지 않게 했습니다.
- 제목과 이전/다음 버튼 고정, 로그 내부 스크롤과 키보드 접근을 유지합니다.

`DevBootstrap-0.1.5-x64.exe`를 받아 Windows 로컬 폴더에서 실행하세요. 이번 화면 변경은 새 EXE에서 반영됩니다. Git clone은 필요 없습니다.

UI 회귀 테스트 9개, 화면 확인과 Windows EXE 빌드를 완료했습니다. 앱에 포함된 화면 파일과 검증한 빌드의 일치도 확인했습니다.

서명되지 않은 Pre-release입니다. 신규 Windows 전체 설치 및 Orca 설치 완료까지의 실환경 검증은 별도로 남아 있습니다.
