# DevBootstrap-0.1.3-x64.exe

PC 상태 화면의 WSL·Orca 버튼을 각각 상태 칸 아래에 정렬했습니다. WSL은 가운데, Orca는 오른쪽에 표시하며 버튼 사이 간격을 고정했습니다.

- WSL이 준비되어 있으면 **WSL 준비됨**, Orca가 설치되어 있으면 **Orca 설치됨**으로 표시하고 버튼을 비활성화합니다.
- 미설치 상태에서만 준비·설치 버튼이 활성화됩니다. **환경 확인 / 새로고침**으로 상태를 다시 검사합니다.
- WSL 최신 버전 비교 기능은 포함하지 않습니다. 필요하면 Windows PowerShell에서 `wsl --update`를 실행하세요.
- 0.1.2의 고정 제목·본문 스크롤·단계 잠금·Orca 공식 설치 파일 다운로드 기능을 포함합니다.

`DevBootstrap-0.1.3-x64.exe`를 다운로드해 Windows 로컬 폴더에서 실행하세요. Git clone은 필요 없습니다. 기존 EXE를 사용 중이라면 이번 UI 변경을 위해 새 파일을 받아야 합니다.

UI 테스트 7개로 버튼 간격·수평 정렬, 설치 여부에 따른 비활성화, 고정 화면과 단계 잠금을 확인했습니다. Windows EXE 빌드와 패키지에 포함된 화면 자산의 일치를 확인했습니다.

서명되지 않은 Pre-release입니다. 신규 Windows 전체 설치와 Orca 설치 창을 끝까지 진행하는 검증은 남아 있습니다. Orca는 공식 설치 파일의 다운로드·체크섬 검증 후 설치 창을 열며, 로그인과 WSL 연결은 사용자가 진행합니다.
