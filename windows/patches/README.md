# Orca 1.4.202 WSL 이름 생성 패치

`orca-1.4.202-wsl-rename.json`은 검증된 원본 `app.asar`에 적용할 UTF-8 바이트 치환이다.
개인 PC 경로나 앱 전체 바이너리를 포함하지 않는다. 오프셋은 원본 기준이며 순서대로 적용한다.

- ASAR 헤더의 main 스크립트 SHA-256 및 블록 해시를 갱신한다.
- main 스크립트 앞부분의 들여쓰기 110바이트를 줄여 전체 크기와 ASAR 파일 오프셋을 유지한다.
- `fCi`에 110바이트를 추가하여 Windows WSL UNC 경로의 배포판을 `sq` 환경 준비와
  반환 실행 대상의 `wslDistro`에 전달한다. SSH 실행 분기는 그대로다.

출처는 2026-09-15 Orca 로컬 수정에서 보관한 원본/패치본이다.
두 파일의 SHA-256은 JSON에 기록되어 있다. KB의 `knowledge/orca-wsl-auto-rename.md`에는
해당 패치 설치·재시작 검증과 사용자 실사용 성공 보고가 구분되어 기록되어 있다.
이 변경 데이터로 재구성한 파일은 그 패치본과 바이트 단위로 같다.

새 버전에는 오프셋을 재사용하지 않는다. 원인 지속 여부와 소스·설치본을 확인하고,
검증된 원본/수정본 및 회귀 검증 근거를 확보한 후 지원 데이터를 추가한다.
